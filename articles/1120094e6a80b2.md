# 概要
pyenv と [poetry](https://python-poetry.org/) を使ってプロジェクト単位（ディレクトリ毎）に python とそのパッケージのバージョン管理を行う方法のまとめ。

なお、本記事は 2023/11/29 時点で以下のバージョンを利用している。

  * pyenv 2.3.1-11-g97039ca1
  * poetry


## プロジェクト毎に環境独立

プロジェクトがあなたのシステムで利用可能なものより新しいPythonを必要とする場合、pyenv と poetry を使うと標準的なワークフローは次のようになります。
```bash
❯ pyenv install 3.11-dev
❯ pyenv local 3.11-dev  # Activate Python 3.11 for the current project
❯ poetry install
```

### 前提条件

上記フローでは`virtualenvs.prefer-active-python` オプション（実験的？）を `true` に設定する必要があるので、defaultでは、
```bash
❯ poetry config --list
cache-dir = "/path/to/cache/directory"
virtualenvs.create = true
virtualenvs.in-project = null
virtualenvs.options.always-copy = true
virtualenvs.options.no-pip = false
virtualenvs.options.no-setuptools = false
virtualenvs.options.system-site-packages = false
virtualenvs.path = "{cache-dir}/virtualenvs"  # /path/to/cache/directory/virtualenvs
virtualenvs.prefer-active-python = false
virtualenvs.prompt = "{project_name}-py{python_version}"
```
となっているので、
```bash
❯ poetry config virtualenvs.in-project true
```
と、有効化しておきましょう。

## Python 本体のバージョン管理

python のバージョンを複数管理したい場合に利用。複数の言語も同様に扱うなら anyenv からの pyenv を利用するのがお勧め。

```bash
$ brew install anyenv
$ anyenv install --init
$ anyenv install pyenv
```

pyenv がインストールできたら、

```bash
❯ pyenv install -l
Available versions:
  2.1.3
  2.2.3
   :
```
で利用可能なバージョンを確認。

たとえば、3.10.5 を入れる場合は、次のように行う。

```bash
$ pyenv install 3.10.5
```

## python のパッケージ管理

[poetry](https://python-poetry.org/)  がプロジェクト毎に閉じた開発環境を作る場合は最適だと思う。

### peotry のインストール

poetry は常に専用の仮想環境にインストールし、他のシステムから隔離する必要があります。

 **Poetry自身の依存関係が誤ってアップグレードされたりアンインストールされたりする原因** になるため、poetryで管理するプロジェクトの環境にインストールすべきではありません。

次のインストール方法は、Poetryが隔離された環境にインストールされることを保証ています。

```bash
❯ pipx install poetry
  installed package poetry 1.7.1, installed using Python 3.12.0
  These apps are now globally available
    - poetry
done! ✨ 🌟 ✨
❯ pipx upgrade poetry
poetry is already at latest version 1.7.1 (location: /Users/gan/.local/pipx/venvs/poetry)
```
なお、`pipx` がインストールされていない場合は、
```bash
❯ brew install pipx
```
とすると [pixp](https://github.com/pypa/pipx) をインストールできます。

### プロジェクトディレクトリの初期化

```bassh
$ poetry new my-package
```
とすると、
```
my-package
├── pyproject.toml
├── README.md
├── my_package
│   └── __init__.py
└── tests
    └── __init__.py
```
というファイル構成を作ってくれる。

#### option

|オプション | 意味 |
|--- |--- |
| --name | 結果のパッケージ名を設定 |
| --src |  プロジェクトの src レイアウトを使用する |
| --readme | readmeファイルの拡張子を指定する。デフォルトは md です。PyPIに公開する場合は、PyPIフレンドリーなREADMEの推奨を |

### 既存プロジェクトディレクトリを poetry 配下に置くには

```bash
$ poegtry init
```

#### option

|オプション | 意味 |
|--- |--- |
| --name | パッケージ名|
| --description | パッケージの説明|
| --author | パッケージの作者 |
| --python | 互換性のある Python のバージョン |
| -dependency | バージョン制約付きでrequireするパッケージ。`foo:1.0.0` の形式であること |
| --dev-dependency | 開発要件。詳細は `--dev-dependency` 参照|
